# DoxiBot

Telegram-бот, который проверяет оформление отчётов `.docx` по стандартным требованиям
или по вашим собственным параметрам,
показывает ошибки, исправляет их автоматически и может вернуть копию документа с примечаниями Word.

## Запуск

```bash
pip install -r requirements.txt
copy .env.example .env      # впишите BOT_TOKEN от @BotFather
python bot.py               # или run.bat
```

При старте бот сам выставляет имя «DoxiBot», описание и меню команд (`/start`, `/rules`, `/help`).

## Как работает

1. Пользователь присылает `.docx`.
2. Бот спрашивает, сколько первых страниц занимают титульный лист и бланк задания — их он не проверяет
   и не исправляет. Ответ можно закрепить в `/settings` (в том числе «определять автоматически»).
3. Бот присылает отчёт: ошибки сгруппированы по правилам, по каждому правилу есть примеры мест и подсказка.
4. Кнопки под отчётом:
   - **🛠 Исправить автоматически** — возвращает `<имя>_DoxiBot.docx` и список того, что осталось поправить вручную;
   - **📝 Примечания в файле** — копия документа с примечаниями Word на проблемных абзацах;
   - **📋 Полный отчёт** — `.txt` со всеми замечаниями.

Границы страниц определяются по разрывам страниц и разметке Word (`lastRenderedPageBreak`). Если разметки
в файле нет, бот честно пишет об этом и определяет титульный лист по первому разделу отчёта
(АННОТАЦИЯ, СОДЕРЖАНИЕ, ВВЕДЕНИЕ или первый заголовок со стилем).

После автоисправления кнопка «Исправить» больше не предлагается: исправление идёт в несколько проходов,
пока замечания не перестанут меняться, поэтому повторный запуск ничего бы не изменил.

## Свои требования (/settings)

Значения по умолчанию — стандартные требования, но каждый пользователь может задать свои:

| Раздел | Что настраивается |
|---|---|
| 🔤 Текст | шрифт, размер, межстрочный интервал, абзацный отступ, выравнивание, интервалы перед/после |
| 📐 Страница | поля, расстояние до колонтитулов, проверка нумерации страниц |
| 🔠 Заголовки | выравнивание структурных элементов и глав, отступ, КАПС для глав и подглав |
| 🧮 Таблицы | минимальный шрифт и интервал в таблицах, знак тире в подписях |
| 🧩 Что проверять | отключение целых групп проверок (рисунки, таблицы, формулы, перечисления…) |
| 📑 Титульный лист | спрашивать / определять автоматически / фиксированное число страниц |

Профили хранятся в `data/settings.json` (по одному на пользователя, только отличия от умолчаний).
Тексты правил и подсказок подставляют значения профиля, поэтому советы всегда соответствуют
настройкам («Шрифт по всему тексту — Arial»).

## Что проверяется

| Область | Правила | Автоисправление |
|---|---|---|
| Страница | поля 30/15/20/20 мм, колонтитулы 1,25 см, номер страницы по центру внизу TNR 14, без номера на титуле, лишний «enter» в колонтитуле | да |
| Текст | Times New Roman 14, чёрный, по ширине, отступ 1,25, интервал 1,5, интервалы перед/после 0, без подчёркивания и полужирного | да |
| Заголовки | структурные элементы — по центру, КАПСОМ, полужирно, без отступа; главы — по ширине, КАПСОМ, отступ 1,25; подглавы — строчными; стили «Заголовок 1/2»; точки | да (кроме ручного перевода КАПСА в строчные) |
| Содержание | «СОДЕРЖАНИЕ»/«ОГЛАВЛЕНИЕ» по виду названий глав, автособираемое, шрифт | название и шрифт |
| Рисунки | обтекание «В тексте», по центру, подпись под рисунком `Рисунок 2.1 – Название`, нумерация по главам (`А.1` в приложениях), ссылки в тексте, запрет «рис.» | формат, выравнивание, нумерация (ссылки обновляются) |
| Таблицы | подпись над таблицей слева `Таблица 1.1 – Название`, «Продолжение таблицы», шапка, шрифт 12–14 и интервал 1–1,5 одинаково во всех таблицах | да |
| Листинги | `Листинг 1.1 – Название` слева без отступа; код без подписи | подписи |
| Формулы | по центру без отступа, пустая строка сверху, номер `(2.4)` справа, нумерация по главам | да |
| Перечисления | пробел вместо табуляции после номера, номер на 1,25 см и текст с 0 см, маркер «–», шрифт и размер самих номеров (берутся из знака абзаца и описания нумерации) | да |
| Источники | дата обращения у электронных ресурсов | нет |

## Структура

```
bot.py                 точка входа (aiogram 3, long polling)
doxibot/
  profile.py           профиль требований (по умолчанию — стандартные) и хранилище настроек
  rules.py             каталог проверок: тексты правил и подсказок с подстановками из профиля
  ooxml.py             текст абзацев, итоговое форматирование с учётом стилей, правки XML
  analyzer.py          классификация абзацев и все проверки
  fixes.py             примитивы автоисправления
  service.py           check / fix / annotate над байтами DOCX
  report.py            тексты для Telegram и полный .txt-отчёт
  handlers.py          обработчики сообщений и кнопок
  storage.py           временное хранение присланных файлов
tests/
  make_samples.py      генерация тестовых отчётов (good/bad)
  run_checks.py        ручной прогон: python tests/run_checks.py file.docx
  test_doxibot.py      проверки движка
  test_flow.py         сценарии бота на заглушках Telegram (вопрос о титульнике, кнопки, настройки)
```

Запуск тестов: `python -m pytest tests`

Новое правило добавляется в два шага: запись в `RULES` (`rules.py`) и проверка в `analyzer.py`
через `self.add(code, block, detail, fix=...)`.
